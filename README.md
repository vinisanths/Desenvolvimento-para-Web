## Apresentação

Este repositório reúne meus estudos, exercícios e atividades da disciplina de Desenvolvimento para Web, do curso de Análise e Desenvolvimento de Sistemas da Universidade CEUMA.

O objetivo é registrar minha evolução na construção de páginas e interfaces web, aplicando os conteúdos estudados em soluções organizadas, funcionais e visualmente consistentes.

> Da estrutura da página à experiência de quem a utiliza: aprender, experimentar e aprimorar.

## Como visualizar as atividades

### 1. Obtenha os arquivos

Faça o download do repositório ou clone-o utilizando o endereço disponível no botão **Code** do GitHub.

### 2. Escolha uma atividade

Acesse a pasta desejada e consulte suas instruções, caso estejam disponíveis.

### 3. Abra a página

Nas atividades compostas apenas por arquivos estáticos, abra o arquivo HTML principal em um navegador.

Se a atividade exigir um servidor local ou ferramentas adicionais, siga as orientações da documentação correspondente.

### 4. Explore e teste

Observe a apresentação, utilize os elementos interativos e teste o comportamento da página em diferentes tamanhos de tela.

## Processo de desenvolvimento

```text
  PLANEJAR           ESTRUTURAR          ESTILIZAR            TESTAR
      |                   |                  |                   |
  Entender a proposta -> Organizar o HTML -> Aplicar o CSS -> Revisar a página
                                                                |
                                                        Aprimorar e repetir
```

A interatividade será incorporada conforme as necessidades de cada atividade, acompanhada de testes e revisão do comportamento da interface.

## Práticas de estudo

Durante o desenvolvimento, busco:

- Manter o código organizado e legível.
- Utilizar nomes claros para arquivos, classes e variáveis.
- Separar estrutura, apresentação e comportamento quando apropriado.
- Considerar diferentes dispositivos e formas de navegação.
- Registrar dificuldades, soluções e melhorias ao longo do aprendizado.
